# プロジェクト自動コンテキスト

## 現在の状態

### TechStackセクション
- **課題**: カード表示の問題が頻発
- **現在の実装**: 1つのstickyコンテナで全カード管理
- **要件**: 全カードが同じ箇所に重なり、同時に上移動

### Globeコンポーネント
- **状態**: 正常動作中
- **特徴**: 東京に赤いマーカー、リアルタイム太陽光
- **注意**: リソース管理が重要

## 技術スタック
- Next.js 15 + React 19 + TypeScript
- Framer Motion (アニメーション)
- Three.js + React Three Fiber (3D)
- Tailwind CSS (スタイリング)

## 頻発する問題パターン

### 1. カード非表示問題
**原因**: `useTransform`による透明度制御
**解決**: `opacity: 1` 固定

### 2. 最後のカード挙動異常
**原因**: 個別stickyの競合
**解決**: 統一stickyコンテナ

### 3. JSXパースエラー
**原因**: タグの開閉不整合
**解決**: 段階的な構造変更

## 学習済みの失敗パターン

### してはいけないこと
- 複数のstickyを同時使用
- `useTransform`での0透明度設定
- 一度に複数の大きな変更
- 動作確認なしの実装完了宣言

### するべきこと  
- 表示担保を最優先
- 段階的な実装
- 各段階での動作確認
- 問題時の即座のロールバック
