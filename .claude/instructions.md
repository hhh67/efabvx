# Claude Code 自動実行指示

## 最優先ルール（必ず遵守）

### 表示担保
- コンポーネントが見えなくなることは絶対に禁止
- `opacity: 1` を維持
- 複雑なアニメーション前に基本表示を確認

### 段階的実装
1. 基本表示の確保
2. 動作確認
3. 機能追加（1つずつ）
4. 各段階で検証
5. 問題時は前段階にロールバック

### 必須チェックリスト
- [ ] 全カードが画面に表示されているか
- [ ] スクロール機能が正常に動作するか
- [ ] エラーが発生していないか
- [ ] TypeScriptエラーがないか

## 技術ガイドライン

### TechStackコンポーネント
- 最後のカードも他のカードと同様に重なる
- 全カードが同時に上に移動
- 1つのstickyコンテナで統一管理

### Three.js/Globe
- リソースの適切な解放
- 動的インポートでSSR回避
- エラー処理の実装

### Framer Motion
- `useTransform`の値範囲を慎重に設定
- 最小透明度を0.3以上に設定
- スクロール進行度のデバッグログ追加

## 緊急時対応

### カード非表示時
```typescript
style={{ 
  opacity: 1,
  display: 'block',
  visibility: 'visible'
}}
```

### エラー発生時
1. 直前の動作状態に戻す
2. 動作確認
3. 問題箇所を特定
4. 安全に再実装

## 自動実行手順

1. **開始時**: このファイルの内容を最優先で適用
2. **実装時**: 段階的実装プロセスを厳守
3. **完了時**: チェックリストで全項目確認
4. **問題時**: 緊急時対応を即座に実行
